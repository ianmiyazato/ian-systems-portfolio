## v0.2

| Date | Decision | Alternatives considered | Why | Value |
|---|---|---|---|---|
| 2026-09-27 | One `routes.manifest.ts` in a source-only `@portfolio/routes` package | Keep the registry inside `@portfolio/chrome` | Remotes, tests, scripts and the shell all need it without pulling in custom elements or a build step | Nav, crawler, screenshots, axe, lens and parity cannot drift apart |
| 2026-09-27 | Remote views declared in the manifest and typed as `Record<ViewId<R>, Component>` | A generated router file per remote | The type is derived from the manifest, so a nav item without a component fails `tsc` without any codegen step | "Every nav item is a real screen" is enforced at compile time and again by the crawler |
| 2026-09-27 | Count the v0.2 deploy budget per project deployment | Count one per milestone run | The stricter reading can never exceed the owner's intent; it means deploying rarely and only changed zones | Free tier stays safe even if every milestone touched shared code |
| 2026-09-27 | `verify:route` and `shots` run as Playwright projects behind small Node wrappers | Stand-alone Node scripts importing TypeScript | Playwright already transpiles TS and manages the four preview servers; Node 22 in CI cannot import the TS manifest without flags | One code path for CI, the crawler and local checks |
| 2026-09-27 | Visual checks keep using Playwright Chromium | Chrome DevTools MCP | The MCP still cannot find Chrome stable in this sandbox (no sudo) | Same 1440 × 900 checks, reproducible in CI |
| 2026-09-27 | The world simulation runs in the browser, seeded and minute-bucketed | A shared backend event stream; Supabase Realtime for everything | Zero cost on the free tier, works offline, and the same seed + time gives the same events in every tab, test and screenshot | Every screen can be live without a server |
| 2026-09-27 | Actions people take are recorded into the world and shared over BroadcastChannel | Separate stores per remote | A refund in Counter must show up in Mesh and Circle in another tab without a backend | Cross-system consequences are visible, still at $0 |
| 2026-09-27 | Balcão becomes Counter; `/mare/ops/balcao*` 308-redirects from the shell and the Maré Ops project, and the host rewrites on its own preview server | Keep the Portuguese name; break old links | US English everywhere, but links in the wild and in v0.1 screenshots must keep working | No dead links after the rename |
| 2026-09-27 | The crawler judges a nav item by whether it becomes current where it lands | Only check that the page is not blank | v0.1's broken views were not blank: `?view=` silently rendered the default view | Catches the exact class of bug the reviewers hit |
| 2026-09-27 | Refunds to Maré Pay reverse installments; store credit carries a +10% bonus and is pre-selected but never forced | Full refund to card; staff pitch credit verbally | Correct money first time; honest retention nudge | Unit-tested refund math and a consistent counter flow |
| 2026-09-27 | Routes can declare their own designed variations (`states`) in the manifest | One variation list per system | v0.2 views each have a distinct variation (frozen account, broken promise, conflicting draft) | Screenshots and axe cover every designed state automatically |
| 2026-09-27 | axe runs with the world pinned (`?live=paused`) | Audit live pages as they stream | Arriving rows animate opacity for 450 ms; auditing mid-animation reports contrast issues that no resting screen has | Deterministic audits of the designed state; live motion is covered by the reduced-motion rules |
| 2026-09-27 | Model release gates show `[value]` for metrics that cannot exist yet | Projected numbers | The operating rule forbids presenting unmeasured metrics as measured | The Models view models the discipline it describes |
| 2026-09-27 | Compatibility is judged for tolerant readers (unknown fields ignored), plus declared consumer reads | Closed content models (additionalProperties false) as the compatibility rule | Under closed models every added field is "breaking", which trains teams to ignore the check; declared reads name the teams that would actually break | Few false alarms, precise real ones |
| 2026-09-27 | The contract checker runs as a unit test and writes a report the Mesh view renders | A separate CI job and a hand-drawn UI | One code path: CI fails on a breaking released version, and reviewers see the exact output | The Contracts screen cannot drift from CI |
